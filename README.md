# Pawsative-Pet-Academy
The Pawsative Pet Academy  delivers a responsive desktop website and a mobile application built strictly from the high-fidelity wireframes to solve Sarah Smith's SME business scenario by addressing the widespread issue of pet owners lacking knowledge in proper training, nutrition, and emergency care. Using a professional Forest Green (#1c522a) and Golden-Yellow (#f0c243) brand theme, the platform organizes seven distinct career and practical skills courses into highly scannable info cards. It features an interactive, database-free shopping cart engine powered by JavaScript and localStorage that tracks user selections across pages, automatically applying tiered business discounts (5% for 2 courses, 10% for 3 courses, and 15% for 4 or more) to show transparent before-and-after calculations right before users finalize bookings with the active CONFIRM PAYMENT or CANCEL action anchors.
